# KAVACH Client Product Requirements

> Current implementation reference, synchronized **29 August 2026**. Source code and runtime configuration are authoritative.

The client serves tourists, Disaster Management, System Admin and emergency fleets.

### Tourist
- account + profile
- destination/date trip creation
- solo/group journeys
- QR/link group join with leader approval and final lock
- one-time manual or AI planning
- live tracking, safety state, SOS, incidents, notifications and history
- view active emergency responder tracking
- Rakshak AI

### Operations
- incident command and hazard/risk workflows
- fleet provisioning and dispatch
- live operational maps and analytics

### Responder fleets
- Active Dispatch
- Live Tracking
- Dispatch History
- live GPS updates and dispatch-state transitions

Product rules must follow backend state transitions rather than simulated frontend-only state.
