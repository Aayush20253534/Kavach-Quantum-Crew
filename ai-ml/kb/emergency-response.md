# Emergency Response

> Current implementation reference, synchronized **29 August 2026**. Source code and runtime configuration are authoritative.

Operational emergency dispatch is initiated through Disaster Management. Police, Fire and Ambulance accounts receive assigned dispatch state and publish live responder location. The affected tourist/group and authorized operations users can view response tracking.

Danger-zone detection or signal-loss escalation does not mean every responder service is automatically contacted; dispatch remains an operational decision.
